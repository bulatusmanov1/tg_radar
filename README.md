# TG Radar

**Анализатор Telegram-чатов**: по экспорту истории находит важные сообщения, дедлайны и вопросы ко мне,
делает сводку за день и строит статистику.

## Позиционирование проекта

Изначальная идея — программа, которая работает в фоне и «пинает», когда в чатах происходит что-то важное.
Для этого нужен доступ к Telegram API (`api_id` и `api_hash` с my.telegram.org), но получить их оказалось
крайне затруднительно: форма регистрации приложения стабильно возвращала ошибку.

Поэтому проект переориентирован с «уведомлений» на анализ:

- источник данных — штатный экспорт истории из Telegram Desktop (JSON), никаких ключей и входа в аккаунт не нужно;
- сводка за день (`day`): где сколько писали, что важного и почему, какие появились дедлайны, кто ждёт ответа;
- дедлайны накапливаются между импортами и «висят» в списке, пока их не отметить выполненными;
- статистика и графики показывают, где и когда идёт основная активность и где прячется важное.

Ежедневная рутина «пролистать десятки веток и не пропустить важное» превращается в
«выгрузить чат и за минуту прочитать сводку». Повторный импорт не создаёт дублей,
поэтому экспорты могут перекрываться по датам.

## Файлы

| Файл | Что внутри |
|---|---|
| `config.py` | все настройки: кто я, веса фильтров и тем, ключевые слова, VIP-отправители |
| `init_db.py` | создание таблиц SQLite |
| `database.py` | класс `Telegram_DB` — все запросы к базе |
| `tg_import.py` | класс `Telegram_Export_Parser` — разбор `result.json`, темы форума, админы, закрепы |
| `filters.py` | `Date_Parser` (даты и дедлайны регулярками) и `Message_Filters` (11 фильтров + штраф за шум) |
| `main.py` | класс `TG_Radar`: команды в терминале, сводка, графики. Запускаемый файл |

Таблицы: `messages` (сообщения + тема + оценка + причины) и `deadlines` (найденные даты).

## Установка и запуск (Windows)

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python init_db.py
python main.py
```

## Как получить экспорт

PS Для демонстрации работы проекта рекомендуется взять учебный чат "ИИМУП | 2026-2028"

1. Telegram Desktop → открыть чат → меню (три точки) → Экспорт истории чата.
2. Снять галочки с фото, видео и файлов (нужен только текст).
3. Формат: **Машиночитаемый JSON**. При желании выбрать период.
4. Получится папка с файлом `result.json` — его путь передаётся команде `import`.

Также поддерживается полный экспорт аккаунта (Настройки → Продвинутые → Экспорт данных Telegram):
из него берутся группы из `WATCH_CHATS` и личные чаты (если `WATCH_ALL_PERSONAL = True`).

## Команды

После запуска `python main.py` программа ждёт команды в терминале:

```
import [путь]     загрузить result.json (по умолчанию EXPORT_PATH из config.py)
day [22.10]       сводка за день (по умолчанию — последний день в базе)
important [N]     важное за N дней (по умолчанию 7)
show <id>         сообщение целиком и почему у него такая оценка
deadlines         ближайшие дедлайны из важных сообщений (deadlines all — из всех)
done <номер>      отметить дедлайн выполненным
unanswered        вопросы ко мне без ответа
search <текст>    поиск по сообщениям
senders           самые активные участники с id (чтобы заполнить VIP_SENDERS)
stats             4 графика на одной картинке (сохраняется в stats/ и открывается)
rescore           перечитать config.py и пересчитать оценки всех сообщений
help / exit
```

## Как считается важность

Каждый фильтр — метод класса `Message_Filters`, возвращает `(баллы, причина)` или `None`.
Баллы складываются; сообщение важное, если сумма ≥ `IMPORTANT_SCORE`.
Вес каждого фильтра задаётся в `WEIGHTS`, вес 0 выключает фильтр.

| Фильтр | Когда срабатывает |
|---|---|
| mention_me | в тексте мой @username |
| name_in_text | обращение по имени |
| reply_to_me | ответ на моё сообщение |
| personal_chat | личный чат |
| vip_sender | админ чата или отправитель из `VIP_SENDERS` |
| keywords | слова из `KEYWORDS` (экзамен, дедлайн, перенос, ведомость...) |
| deadline | в тексте есть дата: дедлайн или событие |
| deadline_soon | дедлайн в ближайшие `SOON_DAYS` дней |
| question_to_me | вопрос, обращённый ко мне |
| announcement | закреплённое сообщение, @all, «внимание», «напоминаю», «коллеги» |
| topic | важная тема форума (`TOPIC_WEIGHTS`) |
| noise (штраф) | «ок», «+», «ахах», стикер или фото без подписи, одни эмодзи |
